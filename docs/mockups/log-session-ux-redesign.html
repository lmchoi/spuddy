①
Done chips: removing the heavy fade + adding a small ✓ makes them feel revisitable rather than locked. The active chip stays green-bordered so the current exercise is still obvious.
②
"+ Add set" row: centred full-width layout reads as a button rather than a data row. The ＋ and text sit together so the eye reads it as one unit. Muted colour keeps it secondary to the Done CTA.
③
Skip set: small muted text link below Done — low priority, always available. Skipping advances to the next set without saving a result for the skipped one. Not a destructive action so no confirmation needed.

# Plan: Walking Skeleton

## Goal
Expo app running on Android (and iOS) with Progress | Settings tab navigation and a pre-commit test hook — no real features, just a clean shell to build v0.1 into.

## Out of scope
- Any real data or features
- SQLite / local storage
- Liftosaur import
- Equipment profile
- Exercise history or charts

## Research findings
- `npx create-expo-app --template tabs` scaffolds Expo Router with tab navigation out of the box, including TypeScript. Saves manual wiring of the router and file-based routing conventions.
- The tabs template ships with example tabs that need to be stripped down and renamed to Progress and Settings.
- Pre-commit hook: a simple `.git/hooks/pre-commit` shell script running `npm test` is enough for now; no need for Husky at this stage.
- Expo targets Android and iOS by default — no platform-specific configuration needed to support both from day one.

## Steps

### 1. Scaffold the app
**What:** Run `npx create-expo-app@latest spuddy --template tabs` inside the workspace root. This gives us Expo Router, TypeScript, and a tab shell.

**Tests to write first:** None — this is pure scaffolding. Confirm the app boots on Android simulator before committing.

**Commits:**
- `chore: scaffold expo app with create-expo-app tabs template`

---

### 2. Strip and rename tabs to Progress | Settings
**What:** Delete the example tabs and screens. Rename/replace with two tabs:
- `Progress` — empty screen, placeholder text "Progress coming soon"
- `Settings` — empty screen, placeholder text "Settings coming soon"

Update tab icons to something appropriate (Expo ships with `@expo/vector-icons`).

**Tests to write first:** A smoke test — render each tab screen and assert the placeholder text is present. This establishes the test harness before any real feature work.

**Commits:**
- `feat: replace example tabs with Progress and Settings shells`
- `test: add smoke tests for Progress and Settings screens`

---

### 3. Wire pre-commit test hook
**What:** Add `.git/hooks/pre-commit` that runs `npm test -- --watchAll=false`. Make it executable.

**Tests to write first:** N/A — verify manually by making a test fail and attempting a commit.

**Commits:**
- `chore: add pre-commit hook to run tests`
